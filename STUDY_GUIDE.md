## 📝 Interview Preparation

### Before Interview
1. **Review** all interview notes
2. **Practice** coding challenges
3. **Understand** time complexity
4. **Prepare** project explanations

### During Interview
1. **Think aloud** - explain your approach
2. **Ask questions** - clarify requirements
3. **Start simple** - brute force first
4. **Optimize** - improve your solution
5. **Test** - with examples

### Common Interview Topics
- Variables and data types
- String manipulation
- List/dictionary operations
- Control flow (if/else, loops)
- Functions and scope
- Error handling
- Basic algorithms
- Time complexity
